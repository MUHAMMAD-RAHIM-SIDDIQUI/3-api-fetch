# API Dashboard

A small React + Vite dashboard for browsing data from two public APIs:

- Random User API
- DummyJSON Products API

The data pages use **TanStack React Query** for fetching, caching, loading states, and errors.

## Run locally

```bash
npm install
npm run dev
```

## Pages

- `/` - dashboard home
- `/user-api` - searchable users
- `/dummyjson` - searchable products

The old Space News API and its related code have been removed.
